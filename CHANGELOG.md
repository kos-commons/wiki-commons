# Changelog

All notable changes to the Wiki Commons guidelines. Versions follow a semantic scheme: a major version only when published identifiers change meaning, a minor version when patterns or recommendations are added, a patch version for editorial corrections.

## 0.3.0 — 2026-10-05

- **Converters for common toolchains** (`converters/`): a remark plugin (`converters/remark/`, `remark-wiki-commons`) that renders `[[free links]]`, `![[embeds]]`, `^block-ids`, and `> [!NOTE]` callouts to the HTML conventions of chapter 08 and stringifies them back; a Pandoc Lua filter (`converters/pandoc/wiki-commons.lua`) for Pandoc's wikilink extension that resolves links, handles embeds, block ids, and callouts, and keeps free links when writing MediaWiki or DokuWiki. Both have tests; CI runs them.
- **Import and export reports** (XFER-13): every `bundle`, `unbundle`, `okf`, `bookstack`, and `mediawiki` command writes an `import-report.md` or `export-report.md` beside its result (summary, fidelity, degraded constructs, dangling links, preserved metadata), unless `--no-report` is given.
- **BookStack Portable ZIP and MediaWiki XML dump** import and export in the reference tooling, mapped in the new **Appendix H**: history with pseudonymized IP addresses, redirects as aliases, categories as tags, templates kept as snapshot envelopes and restored on export to MediaWiki, books and chapters as category pages; Pandoc is used when installed (`WIKI_COMMONS_PANDOC`), with a built-in wikitext converter otherwise, and the manifest records which ran.
- Roadmap: states explicitly that every item is an optional direction or optional tooling, never a requirement on an engine; converters, reports, and the two alignments marked as done; remaining open items narrowed.

## 0.2.0 — 2026-10-04

- **Conformance corpus** (`corpus/`): 24 markup cases, 10 resolution cases, 4 valid and 8 invalid bundles, with expectations generated by the reference implementation and reviewed; `corpus/README.md` documents the formats and how to add cases.
- **Reference tooling** (`tools/wikicommons.py`, package `tools/pwb`): a scanner for the Portable Wiki Markdown profile; conversion between the portable, Obsidian, Foam, Dendron, Logseq, Gollum, and static-site dialects (label order, separators, embeds, comments, callouts, block references, degradation notes); free-link resolution in the MKUP-5 order; bundle building from folders and git-backed vaults with history replay, attachment sidecars, and frontmatter mapping; unbundling to a dialect; Open Knowledge Format export and import; a self-assessment at `tools/wiki-commons.yaml`.
- **Appendix G** aligns the Portable Wiki Bundle with Google Cloud's Open Knowledge Format 0.2 (which Outline exports); the earlier attribution of OKF to Outline is corrected throughout.
- **Portable Page Metadata:** `description` replaces `summary` (which remains an accepted synonym), aligning with OKF, Dublin Core, schema.org, Hugo, Jekyll, and Obsidian Publish. The example bundle and schema are updated.
- Tests (`tests/`) cover the scanner, converter, resolver, round trips (Obsidian vault with git history, Logseq graph, OKF), the corpus, and the schemas; CI runs them.
- Roadmap updated: corpus, tooling, and OKF alignment marked as started; translations are not planned.

## 0.1.1 — 2026-10-04

- Published site: the suite is built with mdBook and deployed to GitHub Pages at <https://kos-commons.github.io/wiki-commons/> by `.github/workflows/pages.yml` on every push to `main`; pull requests run the same checks and build without deploying.
- `tools/build_book.py` assembles the book source from the repository layout; `tools/check_site.py` checks links and anchors in the built site; `tools/check_links.py` ignores the generated `book/` tree.
- Example bundle pages are rendered on the site with their frontmatter shown as a code block.

## 0.1.0 — 2026-10-04 · Working Draft

First complete draft.

- Part I: Overview and Vision; Core Concepts and Landscape; Guiding Principles (PR-1 … PR-18), with Ward Cunningham's original design principles quoted and mapped.
- Part II: a pattern language of 56 patterns in four chapters (NAV-1 … NAV-16, AUTH-1 … AUTH-14, HIST-1 … HIST-12, COLL-1 … COLL-14), each with context, tension, guidance, observed engines, interchange notes, and maturity; three alternative indexes (user journey, structural, cognitive).
- Part III: the Portable Wiki Markdown profile (MKUP-1 … MKUP-20) with its degradation ladder and the document–block bridge; Portable Page Metadata (META-1 … META-14) with Dublin Core and schema.org mappings; the Portable Wiki Bundle (XFER-1 … XFER-15) with manifest, fidelity levels, history and discussion records; API capabilities and link relations (API-1 … API-15); extensibility with snapshot envelopes and a common directive vocabulary (EXT-1 … EXT-13); accessibility, internationalization, and web platform guidance (A11Y, I18N, WEB); security, privacy, and trust (SEC, PRIV, TRUST); licensing and attribution (LIC-1 … LIC-10).
- Part IV: ten conformance profiles plus two tool profiles and a self-assessment format; a roadmap with fourteen open questions.
- Appendices: a landscape of fifty-odd engines with a feature matrix; a twenty-construct syntax crosswalk; a metadata field reference; a walkthrough of the example bundle; a glossary; references with standards versions checked in October 2026.
- Seven JSON Schemas; a complete example bundle; a dependency-free bundle validator and a repository link checker.
